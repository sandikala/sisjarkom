# SISJARKOM v2.1 Realistis

Paket GitHub Pages khusus untuk:

`https://sandikala.github.io/sisjarkom/`

Unggah **seluruh isi folder ini** ke root repository `sandikala/sisjarkom`.

Penanda paket yang benar:

- folder frontend bernama `assets-v21`, bukan `assets`;
- materi pertama adalah **Komponen PC dan kesiapan belajar**;
- dashboard menggunakan `assets-v21/research-lite.js`;
- backend menggunakan `backend/schema-lite.sql`;
- header website menampilkan **V2.1 REALISTIS**.

Folder `assets-v21` sengaja diberi nama baru agar browser tidak menggunakan cache versi awal. Hapus folder `assets` lama dari repository setelah memastikan versi ini berjalan.

Paket PowerPoint dosen dan asesmen tidak disertakan pada website publik karena presenter notes memuat kunci dan rubrik.

Lihat `downloads/PANDUAN_HOSTING.md` untuk konfigurasi GitHub Pages dan Supabase.
